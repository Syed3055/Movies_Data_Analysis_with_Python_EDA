# 🎬 Movie Data Analysis with Python

## 📌 Project Overview

This project focuses on Exploratory Data Analysis (EDA) of a Movie Dataset obtained from Kaggle. The objective is to uncover meaningful insights about movies, genres, ratings, revenues, popularity, budgets, and box office performance using Python data analysis and visualization libraries.

The project demonstrates data cleaning, transformation, analysis, and visualization techniques commonly used in real-world data analytics projects.

---

## 📂 Dataset

**Dataset Source:**  
Movie Dataset for Analytics & Visualization

🔗 https://www.kaggle.com/datasets/mjshubham21/movie-dataset-for-analytics-and-visualization

The dataset contains information about movies such as:

- Movie Title
- Genre
- Release Year
- Budget
- Revenue
- Popularity
- Runtime
- Ratings
- Vote Count
- Production Information
- Box Office Details

---

## 🎯 Project Objectives

The main goals of this analysis are:

- Understand movie industry trends.
- Analyze genre-wise performance.
- Identify top-performing movies.
- Explore revenue and budget relationships.
- Investigate movie ratings and popularity.
- Compare box office collections across genres and years.
- Generate business insights through visualizations.

## 📷 Sample Insights

Some key findings discovered during the analysis:

✅ Certain genres consistently generate higher box office revenue.

✅ Higher movie budgets often correlate with higher revenue, though exceptions exist.

✅ Movie production increased significantly over recent years.

✅ Popularity and vote counts have a strong relationship.

✅ A small percentage of blockbuster movies contribute to a large portion of total revenue.

## 🚀 How to Run the Project

### Clone Repository

```bash
git clone https://github.com/yourusername/movie-data-analysis-python.git
```

### Navigate to Project Folder

```bash
cd movie-data-analysis-python
```

### Install Required Libraries

```bash
pip install pandas numpy matplotlib seaborn jupyter
```

### Launch Jupyter Notebook

```bash
jupyter notebook
```

Open the notebook and execute all cells.
